# ComfyUI故事视频生成器 - 手动搭建流程

## 🎯 概述

本文档提供ComfyUI故事视频生成器的完整手动搭建流程，包含14个节点的详细连接方式和参数配置。

## 📋 节点清单

### **阶段一：内容生成（4个LLM节点）**
1. **故事文案生成** - LLM_party节点
2. **主题提取** - LLM_party节点  
3. **智能分镜** - LLM_party节点
4. **图像提示词生成** - LLM_party节点

### **阶段二：媒体生成（6个节点）**
5. **批处理媒体生成** - StoryBatchMediaProcessor（自定义）
6. **主角图像生成** - RH_APICall节点
7. **主角抠图处理** - RH_APICall节点

### **阶段三：视频合成（4个节点）**
8. **时间轴构建** - StoryTimelineBuilder（自定义）
9. **动画处理** - StoryAnimationProcessor（自定义）
10. **视频合成** - StoryVideoComposer（自定义）

### **第二步：内容生成阶段**

#### **节点2: 故事文案生成**
- **节点类型**: `LLM_api_call`（LLM_party）
- **节点名称**: "故事文案生成"

**配置参数:**
```
model: "deepseek/deepseek-v3"
api_key: "[从API配置获取]"
base_url: "https://openrouter.ai/api/v1"
temperature: 0.8
max_tokens: 1024

system_prompt: "请根据用户提供的【主题】，按照以下结构生成一段历史类短视频口播文案：

1. **悬念开场**：以"【朝代/场景】+ 反常识疑问/断言"开篇，激发观众兴趣（例："古代【某职业】真的比【对比对象】更【形容词】吗？"）。
2. **身份代入**：用第二人称"你"描述主角身份、时代背景及面临的致命危机（需包含具体官职/处境/对手），不要出现"想象一下"等过渡词，直接进入主题。
3. **冲突升级**：
   - 第一层：外部压力（如敌军压境、上级压迫、天灾降临）
   - 第二层：内部瓦解（如下属背叛、资源短缺、疾病蔓延）
   - 第三层：道德困境（如忠义两难、屠城抉择、政斗站队）
4. **破局细节**：主角采取3个递进动作，包含：
   - 震慑手段（当众处决/焚毁证据）
   - 心理博弈（离间计/匿名信）
   - 终极底牌（隐藏密件/借势压人）
5. **主题收尾**：通过主角结局（惨胜/悲壮失败）引出金句，揭示历史规律（如"权力本质/战争真相/人性弱点"）。

**要求**：
- 每段不超过3句话，多用短句制造紧张节奏
- 加入至少2处历史专业术语
- 在关键转折点使用感官描写（气味/触感/视觉冲击）
- 结尾以"这一刻你终于明白…"句式点题
- 生成1000字左右口播文案
- 文案由长短句构成，遇到长句会用逗号分隔成短句，每个短句不能超过19个汉字

**输出要求**：只输出口播字幕文案，不要输出其他任何额外内容，不输出分段说明"

user_prompt: "主题：{{主题输入}}"
```

**连接**: 
- 输入: 连接节点1的输出

#### **节点4: 智能分镜**
- **节点类型**: `LLM_api_call`（LLM_party）  
- **节点名称**: "智能分镜"

**配置参数:**
```
model: "deepseek/deepseek-v3"
api_key: "[从API配置获取]" 
base_url: "https://openrouter.ai/api/v1"
temperature: 0.7
max_tokens: 2048

system_prompt: "你是专业的视频分镜师，擅长将文案智能分割成适合视频制作的场景片段。

## 核心任务
将用户提供的故事文案按照以下规则进行智能分镜：

### 分镜规则（严格执行）
1. **第一句单独成镜**：开篇第一句话必须单独作为第一个场景
2. **后续每2句一组**：从第二句开始，每连续2句话组成一个场景  
3. **场景总数控制**：最终生成7-9个场景，每个场景时长约3-4秒
4. **语义完整性**：确保每个场景内容语义完整，不会出现句子被截断

### 输出格式要求
严格按照JSON数组格式输出，每个场景包含：
- cap: 该场景的文案内容（完整句子）
- desc_promopt: 该场景的视觉描述（用于后续图像生成）

### 视觉描述要求  
- 风格统一：古代惊悚插画风格
- 色调要求：颜色深沉，营造紧张氛围
- 构图要求：突出人物表情和环境细节
- 技术要求：高对比度，线条粗狂清晰

### 示例输出格式
[
  {
    \"cap\": \"第一句完整内容\",
    \"desc_promopt\": \"古代惊悚插画风格：具体场景描述，色彩深沉，线条粗狂，高对比度\"
  },
  {
    \"cap\": \"第二句和第三句的完整内容\", 
    \"desc_promopt\": \"古代惊悚插画风格：具体场景描述，氛围紧张，构图突出\"
  }
]

## 重要提醒
- 必须严格按照JSON格式输出，不要添加任何其他文字
- 确保每个cap字段包含完整的句子，不要截断
- desc_promopt必须详细具体，便于图像生成"

user_prompt: "请对以下故事文案进行智能分镜："

# 重要：通过输入端口连接变量
# 将节点2的输出连接到此节点的 user_prompt_input 端口
```

## 🔌 **重要：LLM节点变量连接方式**

### **ComfyUI LLM_party节点变量接收机制**

**❌ 错误方式：**
```
user_prompt: "故事原文内容：{{故事文案}}"  # 这种方式不工作
```

**✅ 正确方式：**
1. **在user_prompt中写固定文本**：
   ```
   user_prompt: "故事原文内容："
   ```

2. **通过输入端口连接变量**：
   - 将前一个节点的输出连接到LLM节点的`user_prompt_input`输入端口
   - 系统会自动将内容追加：`user_prompt + user_prompt_input`

### **连接步骤：**
1. 在LLM节点中设置基础prompt文本
2. 将数据源节点的输出拖拽到LLM节点的`user_prompt_input`端口（通常在节点左侧）
3. 运行时系统会自动合并内容

### **支持的输入端口：**
- `user_prompt_input` - 用户输入内容
- `system_prompt_input` - 系统提示词输入
- `tools` - 工具列表输入
- `file_content` - 文件内容输入
- `images` - 图像输入

## 🚀 使用流程

1. **搭建工作流**：按照上述节点配置在ComfyUI中逐个添加并连接
2. **配置API密钥**：确保所有API密钥正确配置
3. **输入主题**：在节点1中输入您想要的历史主题
4. **运行工作流**：点击"Queue Prompt"开始生成
5. **等待完成**：整个过程约3-5分钟，最终输出视频路径

## ⚠️ 重要提醒

- **API限制**：注意各API的并发限制，批处理节点默认3并发
- **模型选择**：确保使用DeepSeek-V3模型以获得最佳效果
- **错误处理**：如遇到错误，检查API密钥和网络连接
- **输出路径**：最终视频将保存在ComfyUI的output目录中

## 🔧 故障排除

### **常见问题**
1. **API调用失败**：检查API密钥配置
2. **节点找不到**：确认所有依赖节点已安装
3. **JSON解析错误**：检查LLM输出格式
4. **视频合成失败**：检查所有媒体文件是否生成成功

### **调试建议**  
- 逐个节点测试，确认每个环节输出正确
- 查看ComfyUI控制台日志定位问题
- 检查自定义节点是否正确加载
